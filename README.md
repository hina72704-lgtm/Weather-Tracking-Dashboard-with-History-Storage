# 🌤️ Weather Tracking Dashboard with History Storage

A comprehensive Python application that tracks real-time weather data and stores historical records for analysis.

## ✨ Features

### Core Features
- ✅ **Real-time Weather Data**: Fetch live weather for any city
- ✅ **History Storage**: Save weather data to JSON files
- ✅ **Data Analysis**: View temperature and humidity trends with graphs
- ✅ **Weather Alerts**: Automatic alerts for rain, storms, extreme temperatures
- ✅ **Filter Options**: Filter history by date or city
- ✅ **Error Handling**: Robust error handling for API failures and invalid inputs

### Advanced Features
- 📊 **Temperature Trend Graphs** using matplotlib
- 📈 **Statistical Analysis** (average, min, max temperatures)
- 💾 **Automatic Data Persistence**
- 🔄 **Case-insensitive City Input**
- 🚨 **Weather Warning System**
